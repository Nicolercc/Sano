## One-sentence sync story

Draw → editor lists shapes → lock JSON with the secret in the URL → send over websocket → partner unlocks, merges with what they have, redraws.

Partners are **not** watching your screen. They receive the **recipe** (shape list) and render it locally.

---

## The share link is the room

Starting live collab puts `#room=ROOM_ID,ROOM_KEY` on the URL (`generateCollaborationLinkData` in `excalidraw-app/data/index.ts`).

| Part | Role |
|------|------|
| **ROOM_ID** | Which websocket room to join. Server fans messages to everyone in that room. |
| **ROOM_KEY** | Encryption key. Browser encrypts before send; server only sees ciphertext. Anyone with the full link can decrypt. |

---

## Two pipes (not one video stream)

| Pipe | Message type | What moves | Saved? |
|------|--------------|------------|--------|
| **A — the drawing** | `SCENE_UPDATE` / `SCENE_INIT` | Shape JSON (id, x, y, color, version) | Yes — also Firebase for late joiners |
| **B — the ghost of you** | `MOUSE_LOCATION` | Cursor, username, `selectedElementIds` | No — ~30 fps, volatile |

Constants: `CURSOR_SYNC_TIMEOUT = 33ms`, `SYNC_FULL_SCENE_INTERVAL_MS = 20000` in `excalidraw-app/app_constants.ts`.

**Pipe A path:** `App.onChange` → `collabAPI.syncElements` → `Collab.broadcastElements` → `Portal.broadcastScene` (encrypt) → websocket + throttled Firebase save.

**Pipe B path:** `App.onPointerUpdate` → `Collab.onPointerUpdate` (throttled) → `Portal.broadcastMouseLocation` → `InteractiveCanvas` + `clients.ts` (cursor label).

## How two people draw at once

Each shape has `id` + `version`. Incoming packets go through `reconcileElements` (`packages/excalidraw/data/reconcile.ts`):

- Keep **local** if you are still editing that shape (dragging, typing, resizing).
- Keep **local** if local `version` is higher.
- Tie-break same version with lower `versionNonce`.
- Otherwise take **remote**.

After merge: `handleRemoteSceneUpdate` → `updateScene` with `captureUpdate: NEVER` so receive is not recorded as undo and does not bounce back out. `setLastBroadcastedOrReceivedSceneVersion` prevents echo.

## How the pieces connect (wiring)

**Not** a React tree passing the scene as props. **App** renders **Excalidraw** and **Collab** as **siblings**.

| Connection type | Example |
|-----------------|---------|
| **Props down** | `excalidrawAPI` into Collab; `onChange` / `onPointerUpdate` into Excalidraw; `collabAPI` into ShareDialog |
| **Callbacks up** | Editor `onChange(elements)` → App → `collabAPI.syncElements(elements)` |
| **Imperative API** | Collab calls `excalidrawAPI.updateScene`, `getSceneElements`, `getAppState` |
| **Jotai atom** | Collab publishes `collabAPIAtom` on mount; App/ShareDialog read it without being under Collab in the tree |
| **Ownership** | `Collab` owns `new Portal(this)`; Portal calls back into Collab on socket events |
| **Pure function** | `reconcileElements(local, remote, appState)` — no UI |

## Partner names (random adjective + animal)

Generated by `getRandomUsername()` from `@excalidraw/random-username` (e.g. “Adorable Tiger”). Source: `node_modules/@excalidraw/random-username/src/index.ts`.

| Where you see it | File |
|------------------|------|
| “Your name” in share dialog | `excalidraw-app/share/ShareDialog.tsx` |
| Avatar row + tooltips | `packages/excalidraw/components/UserList.tsx` |
| Label under cursor | `packages/excalidraw/clients.ts` |
| Persisted across reload | `localStorage` key `excalidraw-collab` — `excalidraw-app/data/localStorage.ts` |

Assigned in `Collab.startCollaboration` when username is empty (`excalidraw-app/collab/Collab.tsx`).

## Follow a partner (pick / drop)

Click avatar → `actionGoToCollaborator` (`packages/excalidraw/actions/actionNavigate.tsx`) → `emitUserFollowIntent` → Collab `setUserToFollow` (Jotai `userToFollowAtom`). Partner’s viewport arrives as `USER_VISIBLE_SCENE_BOUNDS`. Click same person again → unfollow.

**Not** drag-and-drop. Separate from library pick-and-drop.

---

## Library pick and drop

`LibraryUnit.tsx` → `onDragStart` writes `excalidrawlibIds` to DataTransfer → `App.handleAppOnDrop` duplicates elements at drop coordinates. HTML5 drag payload, not React props.

---

## Selection

`appState.selectedElementIds: { [id]: true }`. Hit test: `App.getElementAtPosition` / `getElementsAtPosition`. In collab, Portal attaches `selectedElementIds` to `MOUSE_LOCATION` packets so partners see selection highlights.

---

## Undo / redo

`packages/excalidraw/history.ts` — undo/redo stacks of inverse deltas. UI: `actionHistory.tsx`. Deselect-only changes do not clear redo stack. In collab, undo still syncs via `onChange` → `syncElements` like any edit.

## Root files you listed — what they actually do

Those files are the **monorepo shell**, not selection/sync/names:

- `package.json` — yarn workspaces; `yarn start` → `excalidraw-app`
- `CLAUDE.md` — editor vs app split
- `vercel.json` — deploys `excalidraw-app/build`
- `README.md`, `CONTRIBUTING.md`, `docker-compose.yml`, `crowdin.yml`, `tsconfig.json` — docs, i18n, docker, TS config

Behavior lives in `excalidraw-app/` and `packages/excalidraw/`.
